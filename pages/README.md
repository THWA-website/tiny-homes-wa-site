# THWA Website Pages

## Pages

- `homepage.html` — Complete homepage (paste into Wix HTML embed)
- `configurator.html` — 3D Configurator (paste into Wix HTML embed)

## How to use in Wix

1. Open Wix Editor
2. Add → Embed → HTML iframe
3. Click "Enter Code"
4. Paste the contents of the relevant HTML file
5. Set width: 100%, height: 900px (configurator) or full page (homepage)
6. Publish
